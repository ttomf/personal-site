# My Personal site

This is my ([ttomf](https://github.com/ttomf)) personal site, where I showcase projects, write blog posts, and tell the world something about me.

Take a look at it here: [ttomf.cc](https://ttomf.cc)

## Features

- Responsive
- Nice green color scheme
- Dark and light mode
- My projects, achievements and blog
- Contact and GPG key
- SEO, sitemap.xml and robots.txt

## Tech stack

This is a simple website built with pure HTML and CSS, without JavaScript or frameworks.
