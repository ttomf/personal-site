Building my website

2026-10-11

Since I started building web projects, I've wanted to have a place to showcase them. I used Surge and GitHub Pages, but I wanted more control over how my projects were hosted.

Then I found Cloudflare. It offered everything I needed: fast global delivery, reliable infrastructure and server-side code with Workers.

Getting my own domain

Through Hack Club, I got a domain grant, so I decided to get my own domain to host all my projects. Once I had my own domain, I wanted to make better use of it, so I built my website, blog and portfolio here.

I also use my domain for individual projects. Each project can have its own subdomain, making it easy to access and share.

How I built this

I don't really like web frameworks. They add unnecessary complexity and come with tons of JavaScript. I prefer writing HTML directly because it's easy to maintain and doesn't require a build process.

The website is hosted on Cloudflare Pages and deployed directly from GitHub. This makes publishing updates simple: I just push my changes, and Cloudflare takes care of the rest.

What's next

I'll keep improving the design and adding new projects as I work on them. I also want to use this blog to share things I learn and document some of my experiments.
